Stdlib versions by Julia release Rows are standard libraries, columns are Julia releases. Each bar spans the releases that shipped the same stdlib version.

Only releases where the stdlib set changed are listed, so a column stands for every release from that version up to the next column. The newest column may come from a nightly build. Hover a bar for details. Click a column to see what changed in that release, or a row name for its full history.

Arrows point from a stdlib up to the stdlibs that depend on it, so leaves sit at the bottom. Nodes keep their place as the slider moves through releases (arrow keys work too). Hover a stdlib to light up everything it depends on and everything that depends on it; click it for details.

Data is regenerated by ext/HistoricalStdlibGenerator and rendered by docs/make.jl.
